# Puti-AI ESSA｜國小學力檢測備考助手

這是國語、數學及未來其他科目的唯一主要維護儲存庫。

- 科目首頁：https://puti001.github.io/puti-ai-ESSA/
- 國語 ESSA-CHI：https://puti001.github.io/puti-ai-ESSA/CHI/
- 數學 ESSA-MATH：https://puti001.github.io/puti-ai-ESSA/MATH/
- 英語 ESSA-ENG：https://puti001.github.io/puti-ai-ESSA/ENG/

## 檔案安排

- `index.html`：科目首頁。
- `CHI/index.html`、`CHI/app.js`：國語介面與提示詞。
- `MATH/index.html`、`MATH/app.js`：數學介面與提示詞。
- `ENG/index.html`、`ENG/app.js`：英語介面與提示詞。
- `assets/styles.css`：所有科目共用的版型、字級與科目配色。
- GitHub Pages 從 `main` 分支根目錄發布。
- 本機網站原始碼位於 `dist/`；發布時將其內容放在 repo 根目錄。
- `ENG/`：英語介面與提示詞；四至六年級依英語聽力與閱讀評量架構設計。

## 舊網址相容

原本的 `puti-ai-ESSA-CHI`、`puti-ai-ESSA-MATH` 儲存庫只保留入口轉址，不再分別維護網站功能。後續功能更新全部在這個主 repo 完成。
